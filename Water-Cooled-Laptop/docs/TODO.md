# 发布前与复现所需资料 [中文]

**语言 / Language: 中文（简体） | [English](TODO.en.md)**

当前已整理 REV10 三块板的 DXF、STEP、F3D、三个生成脚本、几何检查工具、参数报告、6 张实物照片和3张 CAD 预览。

## 发布前需要确认

- [ ] 项目作者署名，以及 CAD、代码、文档、照片使用的开源许可证；确认后添加正式 `LICENSE`。
- [ ] 如需代上传：提供 GitHub 账号或组织、目标仓库名/链接，并确认公开发布。
- [ ] 补充准确笔记本型号、CPU/GPU 和项目简介。
- [ ] 核对实物照片使用的板件是否与 REV10 完全一致。

## 为他人复现需要补充

- [ ] [BOM](BOM.md) 中其余零件的型号、尺寸、数量与采购信息。
- [ ] 三块板的安装层次、方向、间距，以及螺丝和铜柱长度。
- [ ] 整机装配模型 `CAD/enclosure.step`；目前只有三个独立板件。
- [ ] 带尺寸标注的工程图 `CAD/drawings.pdf`；目前提供 1:1 DXF 和文字尺寸。
- [ ] 铜管加工与焊接步骤、管路连接、供电和排线布置说明。
- [ ] 改装前后测试：室温、负载、CPU/GPU 温度与功耗、风扇/水泵设置、测试时长；噪声数据如有可补。
- [ ] 如果实际使用 ESP32：控制程序、接线图、引脚表、供电规格、传感器型号、依赖版本和烧录说明。若未使用，可以删除预留目录。
